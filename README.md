# exemple_site — Freelance Demo Website

A professional demo website built to showcase freelance web development services. Simulates a real freelance agency website and demonstrates frontend skills to potential clients.

## Tech Stack

| Technology | Usage |
|---|---|
| TypeScript | Main language |
| Next.js | React framework |
| React | UI components |
| Tailwind CSS | Styling |
| Vercel | Deployment |

## Features

- Static/server-rendered landing page built with Next.js
- Services, portfolio sections and contact form
- Fully responsive design (mobile & desktop)
- Optimized for performance and SEO

## Project Structure

```
exemple_site/
├── app/
│   ├── page.tsx          # Main landing page
│   ├── layout.tsx        # Global layout
│   └── components/       # Reusable UI components
├── public/               # Static assets (images, icons)
├── styles/               # Global styles
├── package.json
└── tsconfig.json
```

## Getting Started

**Prerequisites:** Node.js 18+, npm or yarn

```bash
git clone https://github.com/cyberhacker1210/exemple_site
cd exemple_site
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

```bash
# Build for production
npm run build
npm run start
```
